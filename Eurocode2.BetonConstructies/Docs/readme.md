# Kaskon.EurocodeComponenten

**Blazor component library voor berekeningen conform de Eurocode.**  
Deze bibliotheek bevat herbruikbare componenten en logica ter ondersteuning van structurele berekeningen binnen Blazor-applicaties, specifiek afgestemd op de Eurocode-richtlijnen.

## Inhoud

- Componenten voor invoer en weergave van constructieve gegevens
- Ondersteuning voor Fluent UI-integratie
- Validatie- en berekeningsmodellen gebaseerd op Eurocode 2
- Ontwikkeld voor .NET 9 en geoptimaliseerd voor interne Kaskon toepassingen

## Gebruik

> Let op: deze bibliotheek is niet openbaar en vereist toestemming voor gebruik.

Voeg de package lokaal toe aan je project (bijvoorbeeld via een NuGet-feed op een gedeeld netwerk):

```bash
dotnet add package Kaskon.EurocodeComponenten --version 1.0.13
